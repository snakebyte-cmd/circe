Note d’alignement — version de référence et ajouts du fork local

Cette page HTML est la conversion fidèle du manuel officiel Circé v5.4 (septembre 2022, 46 pages). Elle est alignée ici sur la version la plus récente du code disponible sur GitHub :

  • IGNF/circe, branche main @ 0bc8772 — à ce jour le dépôt GitHub ne publie ni tag ni release ; la branche main est donc la référence. La chaîne de version du code est circe_program_version = "circe v5" (circelib 1.3.0, voir circelib/_circelib_version_.h).
  • Fork local : github.com/snakebyte-cmd/circe, branche local-macos-gdal (builds macOS testés, support GDAL 3, scripts de test).

Différences manuel v5.4 ↔ code actuel (options ligne de commande)

Le code (circelib/parser.h, table circeArgumentDefinitions) définit 44 options ; le manuel v5.4 en documente 42. Seules différences :

OptionÉtatDétail
--loadAsVector (-C)présente dans le code, absente du manuel charge les points comme vecteur (mode avancé), compagnon de --processAsVector (-c)
--usagepseudo-option interneaffiche la ligne d’usage, non documentée dans le manuel

Toutes les autres options documentées dans le manuel v5.4 existent inchangées dans le code (noms courts/longs identiques). Pour la liste faisant foi : circeFR --help.

Compléments propres à ce dépôt

  • Construction locale (macOS testé, procédure RHEL 9) : voir BUILD.md.
  • Commandes installées sur macOS : circe (avec GDAL) et circe-plain, zone par CIRCE_ZONE=CirceGUY etc. — voir BUILD.md §4.3.
  • Tests : le dépôt amont embarque des tests par lots (assets/Circe*/<ZONE>.txt + logs de référence test*.log) ; le lanceur scripts/run-tests.sh les exécute et les compare — résultats détaillés dans TESTS.md.
  • Conversion HTML : python3 scripts/pdf2html.py doc/CirceV5ManuelUtilisateur.pdf doc/manuel-utilisateur.html --txt doc/manuel.txt --figdir doc/figures --addendum doc/addendum-alignement.html (nécessite pip install pymupdf).
